Coding mode: what you can say

Say "coding mode on" with BlueJ (Java) or VS Code (C++) in front. Jarvis says back exactly what it wrote. Anything not on this page is ignored, never guessed.

Write a line

"print hello world"
System.out.println("hello world");
"print sum is then sum"
System.out.println("sum is " + sum);
"int sum equals 0"
int sum = 0;
"initialize i equals 0"
int i = 0;
"input int n"
Java n = sc.nextInt(); (Scanner added) · C++ cin >> n;
"sum plus equals i" · "increase count by 2"
sum += i; · count += 2;
"return sum" · "break" · "continue"
As said.
"comment saying check the input"
// check the input
"create a 2D int array called arr with 3 rows and 4 columns"
int[][] arr = new int[3][4]; (no size said: Jarvis asks, you answer "3 rows and 4 columns")
"make an int array called nums of size 5"
int[] nums = new int[5];

Move around

"go to line 12"
That line
"next line" · "previous line" · "go down 3 lines" · "go up 2 lines"
From where the cursor is
"go to the end of the file" · "go to the top"
Last line with code · line 1
"read line 12" · "what's on this line"
Jarvis says it
"select lines 5 to 8"
Selects them

Blocks

"for i from 1 to 10"
for (int i = 1; i <= 10; i++), cursor inside
"for loop where i is equal to 0, i is less than n, i plus plus"
The C way works too
"if x greater than 5" · "else" · "else if …"
Cursor goes inside
"while n not equal to 0"
while (n != 0)
"come out of the loop"
Cursor after the loop's closing brace

Structure

"create a class"
Only if the file has none (BlueJ: a class with another name = New Class)
"create a main method"
Only if there isn't one; else the cursor goes into it
"wrap this inside the main method"
Moves the lines into the main that exists
"put lines 5 to 8 inside a for loop with i from 1 to 3"
Wraps them in a new loop
"wrap this inside a method called show"
New method, and a call where the lines were
"move the cursor inside main"
Cursor to the end of main
"rename sum to total"
Every use, not inside strings

Fix and undo

"undo" · "redo"
Only Jarvis's own last change, from its own record
"delete line 5" · "delete lines 5 to 8"
Never leaves a bracket without its pair
"check my code" · "fix the errors"
Compiles; fixes a missing semicolon or brace itself, else offers a fix
"clear everything"
Asks first; "undo" brings it back
"compile" · "run it" · "go to line 12" · "comment lines 3 to 6"
The editor's own tools

Bigger code AI · asks first

"write a method that checks if a number is prime"
Jarvis says how many lines; the code is in a pop-up
"yes" / "no"
Written only after your yes

Promises

  • Every move, wrap, rename and AI change is compiled first. If it would break the code, it isn't made.
  • Nothing is made twice: one class, one main.
  • Background talk and unclear words are ignored (a pop-up shows what was heard).
  • "Coding mode off" ends it.
